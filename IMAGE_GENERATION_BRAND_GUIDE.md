# 🎨 Mentor Sania — Image Generation & Brand Aesthetic Guide

This guide establishes the permanent aesthetic standard, master prompts, color palette, and format specifications for all generated images, thumbnails, dashboards, and downloadable resource covers across the Mentor Sania platform.

---

## 1. 🎨 Brand Color Palette & Aesthetic Tokens

| Element / Role | Color Code | Description / Usage |
| :--- | :--- | :--- |
| **Background Base** | `#FAF7F2` | Warm Cream, soft non-glare aesthetic |
| **Card & Container BG** | `#EDE4D3` / `#FFFDFA` | Natural linen / Off-white cream |
| **Primary Accent** | `#B5794A` | Terracotta / Warm Clay |
| **Secondary Accent** | `#8A5A34` | Warm Bronze / Muted Earth |
| **Tertiary Accent** | `#4C7A5E` | Muted Olive Green / Success badge |
| **Text & Dark UI** | `#1E1B17` / `#120F0C` | Warm Espresso / Charcoal |
| **Border / Divider** | `#E2D9C9` / `#D9CDB6` | Subtle cream stroke |

---

## 2. 📋 Master Prompt Templates

### A. Downloadable Resource / Article Cover (16:9 or 16:10 Landscape)
> **Master Prompt Formula**:
> ```text
> Flat-lay editorial cover graphic for a downloadable [RESOURCE TYPE — e.g. template / checklist / swipe file / guide], titled "[RESOURCE TITLE]" about [TOPIC — e.g. Pinterest keyword research]. Warm cream (#FAF7F2) background, minimal composition with a mock document/screen preview showing [KEY VISUAL ELEMENT — e.g. a spreadsheet grid / pin template / checklist rows], soft paper texture, terracotta (#B5794A) and olive accent colors matching brand palette, clean modern educator aesthetic, no real logos or text-heavy detail, subtle soft shadow, 16:9 landscape crop, high-resolution flat design photography style.
> ```

#### Placeholders to Fill:
- `[RESOURCE TYPE]`: `template`, `checklist`, `swipe file`, `guide`, `teardown article`.
- `[RESOURCE TITLE]`: Exact title of the resource.
- `[TOPIC]`: Brief topic description.
- `[KEY VISUAL ELEMENT]`: `calendar grid`, `node map`, `flowchart`, `checklist rows`, `analytics chart`.

---

### B. Flagship Dashboard / Mockup (4:3 Aspect Ratio)
> **Master Prompt Formula**:
> ```text
> Clean screen-capture style mockup of a [PRODUCT / SYSTEM NAME] dashboard, showing [FEATURE DESCRIPTION — e.g. grid of keyword-tagged pin templates being edited in a design tool], warm cream (#FAF7F2) UI background, soft neutral tones, minimal browser chrome, high-resolution flat screenshot look, no visible brand logos, professional educator course-material feel.
> ```

---

### C. Feature Highlight / Small Square Graphic (1:1 Aspect Ratio)
> **Master Prompt Formula**:
> ```text
> [STYLE — e.g. Close-up flat-lay / Screenshot-style graphic] of [FEATURE — e.g. a single Pinterest pin template / content calendar tracker / analytics chart], warm cream (#FAF7F2) background with terracotta (#B5794A) accents, clean minimal design, soft lighting, 1:1 square crop.
> ```

---

## 3. 📐 Aspect Ratio Rules

| Location / Section | Preferred Aspect Ratio |
| :--- | :--- |
| **Resources Grid / Homepage Freebies** | `16:9` (CSS `aspect-ratio: 16/10`) |
| **Flagship Main Hero / Showcase** | `4:3` |
| **Flagship Sub-thumbnails / Cards** | `1:1` |
| **Course Cover Badges** | `4:3` or `16:9` |

---

## 4. 🚀 Quick Prompt Generation Checklist
1. Always include `Warm cream (#FAF7F2) background`.
2. Always specify `terracotta (#B5794A)` and `olive accent colors`.
3. Keep composition `minimal`, `flat design photography style`, with `no visible brand logos`.
4. Store generated images under `Media/Resources/` or `Media/Flagship/` with clean lowercase filenames (e.g., `Media/Resources/starter_calendar.jpg`).
